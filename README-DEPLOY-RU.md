# ТЕЙГО — объединённый сайт и сервер (v1.2.0)

В этой папке уже объединены:
- последняя загруженная версия интерфейса `teigo_chat_demo_v5-1.html`;
- сервер `TEIGO_SERVER_FIXED.zip`, версия 1.2.0;
- подключение интерфейса к API и Socket.IO сервера.

## Что работает после публикации
- регистрация и вход через общий сервер;
- общие каналы `общий`, `знакомства`, `мемы`;
- сообщения в реальном времени и история;
- поиск пользователей;
- запросы в друзья, принятие и удаление друзей;
- личные чаты между взаимными друзьями;
- профиль хранится на сервере;
- сервер рассчитан на одновременное подключение нескольких пользователей (в том числе небольшой группы до 10 человек).

## Важно
Дизайн и CSS исходного HTML сохранены. Изменена логика JavaScript, чтобы вместо `localStorage` использовать сервер.
Старые демо-аккаунты из браузера автоматически не переносятся: после публикации каждый пользователь должен зарегистрироваться заново.

Голосовые кнопки пока только включают/выключают микрофон на своём устройстве. Реальных голосовых звонков между пользователями в этой версии нет. Также пока нет загрузки фото/файлов.

## Размещение на Render
1. Распакуй архив и загрузи **содержимое папки** в новый GitHub-репозиторий.
2. На Render выбери **New → Blueprint** и подключи этот репозиторий.
3. Render прочитает `render.yaml` и создаст веб-сервис с постоянным диском для SQLite.
4. В настройках сервиса проверь `JWT_SECRET` (Render генерирует его автоматически).
5. После публикации открой адрес сервиса. Сам сайт откроется на корневом адресе, проверка сервера — `/api/health`.

`render.yaml` использует план Starter и диск 1 GB; это не бесплатная конфигурация. Если нужен бесплатный хостинг, надо отдельно подобрать платформу с постоянным хранением SQLite или заменить SQLite на внешнюю БД.

## Локальный запуск
Нужен Node.js 20 или новее:
```bash
npm install
JWT_SECRET="поставь-длинный-случайный-секрет" npm start
```
Открой `http://localhost:3000`.

## Ограничение по нагрузке
Сервер не содержит искусственного ограничения ровно на 10 аккаунтов. Для небольшой группы до 10 одновременно подключённых пользователей это лёгкий стартовый вариант, но фактическая производительность зависит от выбранного хостинга и сети.
